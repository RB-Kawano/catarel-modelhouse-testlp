# catarel-modelhouse-testlp

カタレルハウス モデルハウス見学会 LP（テスト公開用）

横浜・湘南エリアの建売ブランド「カタレルハウス」のモデルハウス見学会用ランディングページ。

## 構成

- `index.html` — LP本体（CSS/JSインライン）
- `images/` — 画像アセット
- `robots.txt` — クローラー除外設定（テスト公開のため検索エンジンにインデックスさせない）

## 注意

このリポジトリはテスト公開用です。`<meta name="robots" content="noindex, nofollow">` および `robots.txt` で検索エンジンからのインデックスを除外しています。一般公開の際は両方の設定を見直してください。
